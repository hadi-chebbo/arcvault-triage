AI intake and triage pipeline for the fictional company ArcVault (Valsoft AI Engineer assessment). Remote: https://github.com/hadi-chebbo/arcvault-triage (private until submission).

Local markdown: specs and tickets live under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

Default five roles, recorded as a `Status:` line in each issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
